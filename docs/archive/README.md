# Archived Documents

This directory stores documents that completed their purpose but still have historical research value.

## Rules

- Archived documents are read-only.
- New work must not cite archived documents as authority for current behavior, architecture, product facts, or decisions.
- Current constraints must exist in `ARCHITECTURE.md`, `docs/STATE.md`, `docs/DECISIONS.md`, product specs, or an adopted Design Doc.
- When archiving a document, record its original location and archive reason below.
- Delete obsolete content with no historical value instead of preserving it by default.
- Repaid debt and completed/abandoned backlog items do not belong here; git and their carrying documents preserve that history.
